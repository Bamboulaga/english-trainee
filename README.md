# English Trainer V2 — PWA

## Ce que contient cette version
- Installation possible comme PWA sur iPhone/Android quand elle est hébergée en HTTPS.
- 10 nouveaux mots par session.
- Répétition espacée locale.
- Quiz sur les 12 temps principaux.
- Liste de verbes irréguliers.
- Progression sauvegardée dans le navigateur.

## Hébergement
La PWA doit être servie depuis une adresse HTTPS. Une fois hébergée, ouvre l'URL dans Safari sur iPhone, puis :
Partager → Sur l'écran d'accueil → Ajouter.

Pour un vrai produit personnel, la prochaine étape est d'intégrer les 1 000 mots complets et de publier cette V2 sur un hébergeur statique.
