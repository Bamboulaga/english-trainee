# English Trainer V3
V3 PWA : vocabulaire avec saisie, révisions, grammaire avec saisie + indice + QCM de secours, reading, listening, writing, speaking, mini-test, cours et verbes irréguliers.
Les données de progression sont stockées localement dans le navigateur.
Pour installer sur iPhone : héberger en HTTPS puis Safari → Partager → Sur l'écran d'accueil.
